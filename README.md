# Task Manager App

This is a simple task management application built with React and Express.js. It allows users to add, delete, and mark tasks as complete.

## Features

- Add new tasks with a title and description
- View a list of all tasks
- Delete tasks
- Mark tasks as complete
- Edit existing tasks

## Setup Instructions

### Frontend

1. Navigate to the `frontend` directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

### Backend

1. Navigate to the `backend` directory:
   ```bash
   cd backend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the server:
   ```bash
   npm start
   ```

### Environment Variables

Create a `.env` file in the `backend` directory and configure the following variables:

```
PORT=5000
```
